# Отчет тестирования

Цели и задачи тестирования: Наша цель - это покрыть 100 процентов кода тестами и избежать ошибочного поведения


Описание тестируемого продукта: Библиотека которая предоставляет функции для расчета площади и периметра для таких фигур как: круг, прямоугольник, квадрат, треугольник


Область тестирования: 
- circle.py: area(), perimeter()
- rectangle.py: area(), perimeter()
- square.py: area(), perimeter()
- triangle.py: area(), perimeter()


Стратегия тестирования: основанная на модульном тестировании (Unit Testing)


Критерии приемки: 
Успешно выполнено тестов - 20
Провалено тестов - 0

Журнал дефектов: Неправильная работа с отрицательными числами
Метрики качества: 100% тестов пройдено
